## 🚀 Sobre mí

Soy Desarrollador Web Junior y estudiante en la UTN, apasionado por resolver problemas complejos combinando tecnología y análisis de datos. Mi enfoque principal está en el desarrollo backend, automatización de procesos y diseño de bases de datos relacionales.

- 🔭 **Desarrollo actual:** Creando una plataforma de recortes deportivos con un sistema de arquitectura de datos avanzado. La lógica permite asignar múltiples etiquetas a múltiples jugadores en un mismo evento simultáneamente (por ejemplo, en una jugada, un jugador como Messi recibe las etiquetas de "gol" y "disparo de cabeza", mientras que Suárez recibe la etiqueta de "pase" o "centro").
- 🌱 **Aprendizaje activo:** Desarrollo de Smart Contracts con Solidity (proyecto KipuBank), arquitecturas backend con Node.js y metodologías de Testing QA.
- ⚡ **Intereses:** Automatización de tareas complejas con Python (OpenCV), arquitecturas escalables y el ecosistema Web3.
