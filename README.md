## 🚀 Sobre mí

Soy un Desarrollador **Full-Stack** con foco en backend e infraestructura, cursando el último cuatrimestre de la Tecnicatura en Programación y Sistemas en la UTN. Diseño y despliego aplicaciones completas de punta a punta — desde APIs y bases de datos hasta interfaces en React y Angular — resolviendo en el camino problemas reales de producción (autenticación, despliegue, infraestructura). También exploro el desarrollo de aplicaciones descentralizadas (dApps) con Solidity.

### 🎯 Foco Técnico

- ⚙️ **Backend & APIs:** NestJS, Express y Node.js para construir APIs REST robustas sobre bases de datos relacionales y no relacionales.
- 🖥️ **Ecosistemas Full-Stack:** Arquitecturas cliente-servidor completas con React y Angular, desde el diseño de UI hasta el despliegue en producción.
- ⛓️ **Web3 & Smart Contracts:** Desarrollo, validación y despliegue de contratos inteligentes con Solidity para aplicaciones descentralizadas.
- ☁️ **Despliegue & Infraestructura:** Experiencia real resolviendo problemas de producción (Vercel, Render, CORS, cookies cross-domain, workflows automatizados).
